# Ертіс ауданы Ертіс ауылының кейбір көшелерін қайта атау туралы

Қазақстан Республикасының «Қазақстан Республикасының әкімшілік - аумақтық құрылысы туралы» Заңының 14-бабының 4) тармақшасына, Қазақстан Республикасының «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңының 35 бабы 2 -тармағына, Ертіс ауданы Ертіс ауылы тұрғындарының пікірлерін ескере отырып және 2023 жылғы 23 қарашадағы облыстық ономастика комиссиясының қорытындысы негізінде Ертіс ауылының әкімі ШЕШІМ қабылдады:

<a id="p1"></a>

1. Ертіс ауданы Ертіс ауылының келесі көшелері:

   Чайковский көшесін – Марқа Мақауов көшесі;

   Фрунзе көшесін – Қайырбек Ламашәріпов көшесі;

   Степная көшесі – Тәуелсіздік көшесі болып қайта аталсын.

<a id="p2"></a>

2. Кажимухан көшесін Қажымұқан көшесі, Серик Муткенов көшесін Серікбай Мүткенов көшесі болып транскрипциялары өзгертілсін.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p4"></a>

4. Осы шешім оның алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі.

**Ертіс ауылының әкімі**

**Д. Алкенов**
