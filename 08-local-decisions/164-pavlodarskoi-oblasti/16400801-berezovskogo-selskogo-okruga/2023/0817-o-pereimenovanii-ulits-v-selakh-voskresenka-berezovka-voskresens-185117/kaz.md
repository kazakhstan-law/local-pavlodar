# Тереңкөл ауданы Воскресенка ауылдық округі Воскресенка, Березовка ауылдарының көшелерін қайта атау туралы

Қазақстан Республикасының «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңының 35-бабы 2-тармағына, Қазақстан Республикасының «Қазақстан Республикасының әкiмшiлiк-аумақтық құрылысы туралы» Заңының 14-бабы 4) тармақшасына сәйкес, Воскресенка ауылдық округі Воскресенка, Березовка ауылдары халқының пікірін ескере отырып және 2023 жылғы 30 мамырдағы облыстық ономастика комиссиясының қорытындысы негізінде ШЕШТІМ:

<a id="p1"></a>

1. Тереңкөл ауданы Воскресенка ауылдық округінің Воскресенка ауылындағы «Молодежная» көшесі «Мерей» көшесі болып қайта аталсын.

<a id="p2"></a>

2. Тереңкөл ауданы Воскресенка ауылдық округінің Березовка ауылындағы «Мира» көшесі «Бейбітшілік» көшесі, «Советов» көшесі «Астана» көшесі болып қайта аталсын.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p4"></a>

4. Осы шешім оның алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Воскресенка ауылдық округінің әкімі**

**О. Жаркина**
