# О дополнительных мерах по защите прав субъектов малого предпринимательства

> *Сноска. Утратило силу решением акима Павлодарской области от 29.10.2004 № 25.*

В целях защиты прав субъектов малого предпринимательства принимаю РЕШЕНИЕ:

<a id="p1"></a>

1. Создать межведомственный совет по защите прав субъектов малого предпринимательства.

<a id="p2"></a>

2. Утвердить положение о межведомственном совете по защите прав субъектов малого предпринимательства.

<a id="p3"></a>

3. Акимам городов и районов области образовать аналогичные советы на местах.

<a id="p4"></a>

4. Ввести с 1 февраля 1999 года в действие журнал учета проверок деятельности субъектов малого предпринимательства контролирующими органами.

<a id="p5"></a>

5. Утвердить Положение о порядке проведения проверок деятельности субъектов малого предпринимательства контролирующими органами области.

<a id="p6"></a>

6. Уполномоченным органом по реализации данного решения определить департамент экономики области.

<a id="p7"></a>

7. Контроль за исполнением настоящего решения возложить на заместителя акима области Оспанова М.Н.

<a id="p8"></a>

8. Решение акима области от 29 августа 1996 года № 137-а межведомственном совете по координации проверок индивидуальных предпринимателей и юридических лиц считать утратившим силу.

   **Аким области**

   **Г. Жакиянов**
