# Шағын кәсіпкерлік субъектілерінің құқықтарын қорғау жөніндегі қосымша шаралар туралы

> *Ескерту. Күші жойылды - Павлодар облысы әкімінің 29.10.2004 № 25 шешімімен.*

Шағын кәсіпкерлік субъектілерінің құқықтарын қорғау мақсатында ШЕШІМ қабылдаймын:

<a id="p1"></a>

1. Шағын кәсіпкерлік субъектілерінің құқықтарын қорғау жөніндегі ведомствоаралық кеңес құрылсын;

<a id="p2"></a>

2. Шағын кәсіпкерлік субъектілерінің құқықтарын қорғау жөніндегі кеңес туралы Ереже бекітілсін;

<a id="p3"></a>

3. Облыстың қалалары мен аудандарының әкімдері жергілікті жерде осындай кеңестер құрсын.

<a id="p4"></a>

4. 1999 жылғы ақпанның 1-нен бастап бақылаушы органдардың шағын кәсіпкерлік субъектілері қызметін тексерулері есебінің журналына енгізілсін.

<a id="p5"></a>

5. Облыс бақылаушы органдарының шағын кәсіпкерлік субъектілері қызметіне тексеру жүргізу тәртібі туралы Ереже бекітілсін.

<a id="p6"></a>

6. Осы шешімді іске асыратын орган болып облыс экономика департаменті белгіленсін.

<a id="p7"></a>

7. Осы шешімнің орындалуына бақылау жасау облыс әкімінің орынбасары М.Н. Оспановқа жүктелсін.

<a id="p8"></a>

8. Облыс әкімінің 1996 жылғы 29 тамыздағы «Жеке кәсіпкерлер мен заңды тұлғаларды тексеруді үйлестіру жөніндегі ведомствоаралық кеңес туралы» № 137-а шешімі күшін жойған болып саналсын.

   **Облыс әкімі**

   **Ғ. Жақиянов**
